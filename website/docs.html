Documentation

Everything you need to get started with STTpro and make the most of its features.

Installation

STTpro runs on Windows 10 (version 1903 or later) and Windows 11. It requires the .NET 8 Desktop Runtime, which the installer will offer to set up automatically if it is not already present.

System Requirements

  • Windows 10 version 1903+ or Windows 11
  • .NET 8 Desktop Runtime
  • A working microphone
  • An internet connection (for API calls)
  • Approximately 30 MB of disk space

Install Steps

  1. Download the latest installer from the Download page.
  2. Run STTpro-Setup.exe and follow the on-screen prompts. The installer will place STTpro in your AppData\Local\STTpro folder by default.
  3. When installation completes, STTpro launches and appears in your system tray (bottom-right of the taskbar).
  4. On first launch you will be prompted to enter your OpenAI API key. See the next section for details.
STTpro can be configured to start automatically with Windows. You can enable this in Settings > General > Start with Windows.

API Key Setup

STTpro uses your own OpenAI API key for Whisper transcription and, optionally, GPT-powered Smart Prompts. You only pay OpenAI for what you use -- there are no additional API fees from STTpro.

Getting an OpenAI API Key

  1. Visit platform.openai.com and create an account (or sign in if you already have one).
  2. Navigate to API Keys in the left sidebar of the OpenAI dashboard.
  3. Click Create new secret key, give it a name like "STTpro", and copy the key.
  4. Back in STTpro, open Settings and paste the key into the OpenAI API Key field.
Your API key is stored locally on your machine using Windows DPAPI encryption. It is never sent to STTpro servers.

Estimated API Costs

Whisper API pricing is based on audio duration. As of early 2026, the cost is roughly $0.006 per minute of audio. A typical 15-second dictation costs a fraction of a cent. Check OpenAI's pricing page for current rates.

Verifying Your Key

After entering your key, click the Test Connection button in Settings. STTpro will make a small test request. If you see a green checkmark, everything is working. If the test fails, double-check that:

  • The key was copied completely (no trailing spaces)
  • Your OpenAI account has billing enabled with available credits
  • Your firewall is not blocking outbound HTTPS requests

Your First Transcription

Once your API key is configured, you are ready to start dictating.

  1. Open any application with a text field -- a browser, Notepad, Word, or a chat window.
  2. Click into the text field so it has focus.
  3. Press Ctrl + Shift + S (the default hotkey) to start recording. You will see a small visual indicator confirming that STTpro is listening.
  4. Speak naturally into your microphone. When you are finished, press the same hotkey again to stop, or simply wait -- silence detection will stop the recording automatically.
  5. After a brief moment, your transcribed text will be typed into the focused text field.
If no text appears, make sure your microphone is selected correctly in Settings > Audio Device and that your API key is valid.

Global Hotkeys

STTpro registers system-wide keyboard shortcuts so you can start and stop recording from any application without switching windows.

How It Works

When you press your recording hotkey, STTpro begins capturing audio from your selected microphone. The hotkey works even when STTpro's window is minimized or hidden in the system tray. A visual overlay briefly appears to confirm the recording has started.

Customizing Hotkeys

You can change all hotkeys in Settings > Keyboard Shortcuts. Click the shortcut field next to any action, then press your desired key combination. STTpro supports combinations using Ctrl, Shift, Alt, and Win modifiers.

Avoid hotkeys already used by Windows or other applications. If a conflict is detected, STTpro will warn you when saving.

Smart Prompts

Smart Prompts let you post-process transcriptions using GPT before the text is typed out. This is useful for cleaning up grammar, reformatting text, translating, or applying custom transformations.

Setting Up a Smart Prompt

  1. Open Settings > Smart Prompts.
  2. Click Add Prompt to create a new prompt profile.
  3. Give the prompt a name (e.g., "Clean Grammar" or "Translate to Spanish").
  4. Write the instruction in the prompt field. For example: Fix any grammar or spelling errors. Keep the same tone and meaning.
  5. Optionally, assign a dedicated hotkey to this prompt so you can trigger it directly.

Example Prompts

  • Grammar cleanup: Fix grammar and spelling errors without changing the meaning.
  • Bullet points: Reformat this text as a concise bulleted list.
  • Translation: Translate the following text to French.
  • Email tone: Rewrite this as a professional email, keeping it concise.
  • Summary: Summarize this text in one or two sentences.
Smart Prompts require a GPT-capable model on your OpenAI account. The prompt processing adds a small amount of latency and cost per use.

Transcript History

Every transcription you make is saved locally so you can review, search, and copy past results at any time.

Viewing History

Open the STTpro main window and click the History tab. Each entry shows:

  • The full transcribed text
  • Timestamp (date and time)
  • Recording duration
  • Detected language
  • The target application window title

Searching and Copying

Use the search bar at the top of the History panel to filter entries by keyword. Click any entry to select it, then use the Copy button or press Ctrl + C to copy the text to your clipboard.

Managing History

You can delete individual entries by selecting them and pressing Delete, or clear all history from Settings > History > Clear All. History is stored locally in your AppData folder.

Silence Detection

STTpro continuously monitors audio levels during recording. When it detects that you have stopped speaking for a configurable period, it automatically ends the recording and sends the audio for transcription.

Configuration

  • Silence Threshold: The volume level (in dB) below which audio is considered silence. Lower values are more sensitive. Default: -40 dB.
  • Silence Duration: How long silence must persist before recording stops automatically. Default: 2.0 seconds.
  • Enable/Disable: You can turn silence detection off entirely if you prefer to always stop recording manually with the hotkey.
If silence detection triggers too early in a noisy environment, try lowering the threshold (e.g., -50 dB) or increasing the duration to 3.0 seconds.

Settings

The Settings panel is accessible from the system tray icon or the main window. Below is an overview of all configurable options.

General

  • Start with Windows: Launch STTpro automatically when you sign in.
  • Start minimized: Launch directly to the system tray without showing the main window.
  • Notification sounds: Play a short sound when recording starts and stops.
  • Visual overlay: Show a small on-screen indicator while recording.

Transcription

  • Language: Set a preferred language or leave on Auto for automatic detection.
  • Model: Choose the Whisper model variant. whisper-1 is the default and recommended option.
  • Temperature: Controls transcription creativity/variation. Default 0 produces the most deterministic results.

Output

  • Auto-paste mode: Choose between simulating keystrokes (default) or pasting from clipboard.
  • Append newline: Automatically add a newline after each transcription.
  • Typing speed: Adjust the delay between simulated keystrokes. Increase this if characters are dropped in some applications.

Privacy

  • API Key: Enter or update your OpenAI API key.
  • Clear history on exit: Automatically delete all transcript history when STTpro closes.

Audio Devices

STTpro can record from any audio input device connected to your computer.

Selecting a Microphone

Go to Settings > Audio Device to see a dropdown list of all available input devices. Select the microphone you want to use. The default option uses whatever Windows has set as the default recording device.

Testing Your Microphone

Click the Test button next to the device selector. STTpro will briefly record from the selected device and display the audio level meter. If you see the meter responding to your voice, the device is working correctly.

If you connect or disconnect a microphone while STTpro is running, click Refresh to update the device list.

Tips for Best Results

  • Use a dedicated microphone rather than a built-in laptop mic for better clarity.
  • Position the microphone 6-12 inches from your mouth.
  • Reduce background noise where possible -- Whisper handles some noise well, but a quieter environment produces better accuracy.
  • Check your Windows Sound settings to make sure the correct device is set and the input level is adequate.

Troubleshooting

If something is not working as expected, check the common issues below.

No text appears after recording

  • Verify your API key is valid by running Settings > Test Connection.
  • Make sure a text field has focus before you stop recording. STTpro types into whichever window is active.
  • Check your internet connection -- Whisper requires an API call to OpenAI servers.
  • Review the History tab. If the transcription appears there but not in your app, the issue is with text insertion. Try switching to clipboard paste mode in Settings > Output > Auto-paste mode.

Recording does not start

  • Confirm your hotkey is not conflicting with another application. Try changing it temporarily in Settings.
  • Make sure STTpro is running -- check for its icon in the system tray.
  • On some systems, running STTpro as administrator may be required for global hotkeys to work in elevated windows.

Microphone not detected

  • Open Windows Settings > System > Sound and verify your mic appears under Input devices.
  • Make sure no other application has exclusive control of the microphone.
  • Click Refresh in STTpro's audio device settings after plugging in a new device.

Poor transcription accuracy

  • Use a higher-quality microphone and reduce background noise.
  • Speak clearly and at a moderate pace.
  • If you primarily speak a language other than English, set the correct language in Settings > Transcription > Language instead of using auto-detect.
  • Check that the silence detection threshold is not cutting off your speech early.

High latency

  • Transcription speed depends on your internet connection and the OpenAI API response time.
  • Shorter recordings are transcribed faster. If silence detection is disabled, consider enabling it to send smaller audio chunks.
  • Smart Prompts add an additional API call. Disable them if you need minimum latency.

Characters are dropped or garbled when typing

  • Some applications process keyboard input slowly. Increase the Typing speed delay in Settings > Output.
  • Alternatively, switch to Clipboard paste mode which pastes the entire text at once.

Frequently Asked Questions

Is STTpro free?

STTpro offers a free trial with a limited number of transcriptions. After the trial, a one-time license purchase unlocks unlimited use. You also pay OpenAI directly for API usage, which is typically very low cost. Visit the Buy page for pricing details.

Does STTpro work offline?

No. STTpro requires an internet connection to send audio to the OpenAI Whisper API for transcription. There is no local transcription mode at this time.

What data does STTpro collect?

STTpro does not collect or transmit your audio, transcriptions, or personal data to our servers. Audio goes directly from your machine to OpenAI's API. License validation requires only your license key. Read our Privacy Policy for full details.

Can I use a different transcription provider?

Currently STTpro is built around the OpenAI Whisper API. Support for additional providers may be added in future updates.

Does it work with multiple monitors?

Yes. The recording overlay and all functionality work across multiple monitors. STTpro types into whichever text field has focus, regardless of which monitor it is on.

How do I update STTpro?

STTpro checks for updates automatically on launch. When an update is available, you will see a notification with the option to download and install it. You can also check manually from Settings > About > Check for Updates.

How do I uninstall STTpro?

Open Windows Settings > Apps > Installed apps, find STTpro in the list, and click Uninstall. This removes the application and its shortcuts. Your transcript history and settings in AppData are preserved unless you manually delete them.

I need more help. How do I get support?

If your issue is not covered here, reach out via email at support@sttpro.com. Include your STTpro version number (found in Settings > About) and a description of the problem.
